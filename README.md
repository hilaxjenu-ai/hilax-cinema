# Hilax Cinema Android App (GitHub Actions APK Builder)

Loads `https://hilax.vinokaran.my.id:5000/` inside a full-screen Android WebView with back-navigation, download handling, and hardware-accelerated video playback.

## How to Build APK on GitHub
1. Extract this ZIP and upload all files/folders to your GitHub repository root (`main` branch).
2. Open the **Actions** tab in your GitHub repository.
3. Wait for **Build APK** to finish with a green checkmark, then download `HilaxCinema-apk` from **Artifacts**.
